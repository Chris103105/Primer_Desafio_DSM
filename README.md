##  Descripción del Proyecto
Calculadora básica que permite al usuario realizar operaciones matemáticas fundamentales.

##  Características y Funcionalidades
* **Operaciones Aritméticas:** Soporte para suma, resta, multiplicación y división con números enteros y decimales.
* **Validación Robusta de Entradas:** 
  * Prevención de campos vacíos mediante notificaciones emergentes (`Toast`).
  * Validación matemática para evitar la división entre cero.
* **Navegación y Paso de Parámetros:** 
  * `MainActivity`: Interfaz de captura de datos y validación.
  * `ResultActivity`: Interfaz receptora (vía `Intent`) encargada de procesar la lógica matemática y presentar el resultado formateado.


##  Tecnologías Utilizadas
* **Lenguaje:** Kotlin
* **Entorno de Desarrollo:** Android Studio
